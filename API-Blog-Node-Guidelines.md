# Diretrizes - API Blog Node.js

- O copiloto deve responder e perguntar sempre em português brasileiro.
- Não usar frameworks HTTP (Express, Fastify, NestJS).
- Usar Node.js nativo para servidor HTTP.
- Conexão com PostgreSQL via `pg`.
- Migrations com `postgrator`.
- IDs únicos com `nanoid`.
- Validação de dados com `zod`.
- Testes end-to-end com `supertest`.
- Conteúdo da IA sempre em português brasileiro e em Markdown.
- Encerrar conexões corretamente.
- Usar status HTTP coerentes.
